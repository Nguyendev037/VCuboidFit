# Sample run ("Chạy thử dữ liệu mẫu")

Real VCuboidFIT output (rare_v24, multisensor: PointPillars + OpenCV + OpenCLIP) on 121 frames of nuScenes v1.0-mini,
exported by `web/scripts/export-sample-run.mjs` from a local job. Camera images are resized to 800 px wide.
